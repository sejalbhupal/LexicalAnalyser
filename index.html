About LexiScan

LexiScan performs the lexical analysis phase of a compiler: it scans C/C++ source code and groups the raw characters into tokens — keywords, identifiers, literals, operators, and delimiters — while ignoring whitespace and comments.

The scanning engine is a hand-written C++ program (no regex, no external parsing libraries). An Express/Node.js server acts as the middleware: it receives source code or an uploaded file from this browser interface, runs the compiled C++ analyzer as a child process, and returns its JSON result.
